# 智算中心投建运 · 投资逻辑框架

**视角：** PE/VC 一级股权投资 + 产业投资
**当前阶段：** 高速成长期（2026-2027 窗口期，在建产能集中释放）

---

## 一、三句话判断

> **第一句：智算中心已经从"抢 GPU"进入"抢电力基础设施"阶段——变压器、燃气轮机、柴发比芯片更能卡住项目交付。**
> 投建运的最大瓶颈不在资金，在设备交期和电力接入。

> **第二句：选址是投建运胜负手——电价差、PUE 约束、上架率预期决定同一个项目的 IRR 从 6% 到 18% 的差距。**
> 同样的资本开支，选址不同，回报差 3 倍。

> **第三句：运营能力正在取代"包租公"模式成为估值核心——上架率、算力利用率、电力成本对冲，决定智算中心是资产还是包袱。**
> 从"算力+能源一体化"运营商（润泽 2025 净利 +182%）看，运营才是终局能力。

## 三、投建运三阶段投资策略

### 3.1 投（投资决策）—— 优先布局

1. **选址经济学研究** ⭐⭐⭐⭐⭐
   - 电价差、PUE 硬约束（≤1.15）、上架率预期是 IRR 的决定性变量
   - 西部绿电区（乌兰察布/和林格尔）vs 东部高需求区（长三角）的回报权衡
   - **关键验证**：绿电直连审批进度、区域电网承载力、客户签约意向

2. **数据中心 REITs / Pre-REITs** ⭐⭐⭐⭐
   - 世纪互联 REITs 首发验证了资产证券化路径
   - 重资产+稳定现金流=REITs 天然标的
   - **关键验证**：底层资产上架率、租约结构、现金流稳定性

3. **建设期设备供应链** ⭐⭐⭐⭐
   - 变压器 160 周交付周期 = 结构性供不应求
   - 中国变压器出口 2025 年 +36.3%，对美出口 +182%
   - **关键验证**：产能扩张周期、客户认证、订单能见度

### 3.2 建（工程建设）—— 重点跟踪

4. **存量厂房改造智算中心**
   - 政策明确推进存量改造，避开新建审批周期
   - 改造比新建节省 40-60% 工期
   - **关键验证**：机电改造方案、能耗指标达标能力

5. **智算代运营/托管服务**（新机会）
   - 大量新建项目缺乏运营能力，代运营需求爆发
   - **关键验证**：PUE 管理能力、客户留存、电力成本优化幅度

### 3.3 运（运营管理）—— 关注等待

6. **算力定价平台/按Token计费**
   - 从包机柜到按 Token 计费是行业演进方向
   - **关键验证**：定价模型稳定性、客户接受度、毛利结构

7. **重资产自建智算中心**（谨慎）
   - 适合产业资本与战略投资，财务投资回报周期过长
   - **关键验证**：绿电直连、客户长协、区域电价政策

## 四、关键风险

| 风险 | 说明 | 对冲 |
|------|------|------|
| **供给过剩** | 2026-2027 在建产能集中释放，上架率承压 | 优选有客户长协/自用需求的运营商 |
| **设备交期风险** | 变压器/柴发/液冷交期拉长，项目延期 | 提前锁定设备、多元化供应链 |
| **电价政策变化** | 绿电直连政策、现货市场价格波动 | 电力成本对冲工具箱（PPA/储能/需求响应） |
| **技术路线风险** | 散热（液冷 vs 浸没）、供配电（HVDC）路线未定 | 跟随头部客户技术选型 |
| **融资成本上升** | 重资产项目对利率敏感 | REITs/Pre-REITs 多元融资 |
