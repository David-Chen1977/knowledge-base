# 从卖机柜到卖Token：算力定价的三次演进与收费模式终局

> **公众号摘要**（发布时填入摘要栏，不进入正文）：同样一个机柜，有人一年收 7 万，有人收 36 万——差别不在装修，在计费单位。从卖机柜到卖卡时再到卖 Token，每次切换都是一次风险换手。上周 DeepSeek 把「峰谷电价」搬进了 API，算力定价的终局，正在照着电力市场的剧本走。

先说句掏心窝的：我干了 20 年地产，管过基金、做过经营性物业的募投管退，最近几年又扎进电力交易和 HVDC 供电架构。现在开这个号，就是想用「资产 + 电力」的双重视角，把算电协同这件事讲清楚。本文由 AI 帮我整理资料和初稿，但每一个判断——比如为什么我说算力定价在抄电力市场的作业——都是我自己的体感。AI 没去过项目现场，我没让它替我做判断。也欢迎你在评论区拍砖——这个号不是我一个人的学习笔记，是咱们一起研习的地方。

上个月有个做园区的朋友问我：同样一个机柜，凭什么有的智算中心一年收 7 万，有的能收 36 万？

传统 IDC 单机柜年租金大约 7.2 万元，装了 GPU 的训练型机柜能到 36.8 万元甚至更高（钛媒体，2025，行业口径）。五倍价差，差的不是装修，是**计费单位**。二十年前数据中心卖「空间」，十来年前云厂商切到「时间」，今天大模型把账算到了「产出」。三次演进，每一次都是商业模式的革命，不只是技术升级。

### 三次演进：空间 → 时间 → 产出

**1.0 卖机柜，本质是收租。** 机柜、电力、制冷打包，客户把服务器搬进来按月交钱。这生意我太熟了——就是商业地产：铺位租出去，空着你也得交物业费、还贷款。命门是空置机柜照样烧钱，所以上架率决定生死，这也是上一篇「65% 生死线」的由来。

**2.0 卖卡时，把计费切到小时。** 云计算让中小客户不用为整柜买单，用多少小时付多少钱。但卡时卖的是「设备被占用的时长」，不是你真正得到的东西：任务间隙的空转照计费；轻量推理和重型训练挤在同一口价里；多任务分时复用一张卡，账根本算不清（天翼云开发者社区）。就像酒店按晚计费——你入住三晚，哪怕两晚在外头玩，钱照付。

**3.0 卖 Token，直接按产出收钱。** 黄仁勋反复讲的 Token Factory 就是这个逻辑：GPU 是生产设备，电力是能源，数据是原材料，Token 才是最终产品——数据中心从「存文件的仓库」变成了「生产 Token 的工厂」。2026 年 WAIC 上头部厂商和运营商集体推出 Token 按量计费，中国移动干脆成立了集团级「Token 办公室」，移动云按量计费加资源包，新用户先送 2500 万 Token（财新，2026.06）。

一句话：从卖毛坯房，到卖房晚，到按菜收费——饭店不管后厨几口锅，你吃几道菜付几道菜的钱。按产出收费还有一层深意：模型厂商第一次被直接拷问「一度电能出多少个 Token」——算和电的账，从此在同一个计费单位里见面了。

### 每次换计费单位，都是一次风险换手

这是最容易被忽略的一层：**计费单位不是会计技术，是风险分配合同。**

卖机柜时，利用率风险全在客户——柜子空转，房东照收。卖 Token 时，风险整个翻到供给侧——客户按实际产出付钱，设备空转、点亮率低，亏的全是算力方。所以 Token 计费不只是「更便宜」，它逼着运营商把上一篇讲的点亮率，从「客户的事」变成「自己的命」。

还有一种高级玩法：CoreWeave 式批发长约，take-or-pay——用不用都全额照付，签约先付 15%–25% 预付款，合同期 4–5 年，而且是签了合同才建机房（OFweek，2025.12）。把利用率风险和建设风险打包卖给大客户，这和电力市场的中长期合约一模一样。

### 六种计费模式对照表（建议收藏）

| 模式 | 计价单位 | 类比 | 适用场景 | 利用率风险谁扛 |
| --- | --- | --- | --- | --- |
| 机柜租赁 | 元/柜·月 | 商业地产收租 | 自带服务器、长期托管 | 客户 |
| 按功率（kW） | 元/kW·月 | 按面积收物业费 | 高密度部署、批发型 | 客户 |
| 批发长约 take-or-pay | 集群·年 | 整层租给主力店 | 头部模型厂、稳定训练 | 客户全扛+预付款 |
| 按卡时 | 元/GPU·时 | 酒店按晚计费 | 弹性训练、临时峰值 | 双方分担 |
| 按 Token | 元/百万 Token | 计件工资 | 推理、Agent、中小企业 | 算力方全扛 |
| 订阅+分成 | 月费+流水分成 | 商场联营抽成 | 深度绑定的大客户 | 利益共享 |

看任何一个算力项目，先对号入座是哪一行，再看它的风险假设成不成立——上一篇的生死线模型，在每一行里要用完全不同的口径算。

### 价格战的拐点：谁稀缺，谁定价

Token 这层的价格，2026 年走出一个深 V。先是熟悉的剧情：2024 年豆包把输入价打到 0.8 元/百万 Token，通义千问主力模型跟进降 97%。然后是反转：摩根士丹利统计，国内平均每百万 Token 输入价从 2025 年一季度的 3.3 元回升到 2026 年二季度的 4.9 元，输出价从 12.2 元涨到 21.9 元（36氪，2026.08）。Kimi K3 的输出价更是直接比前代涨了约 4 倍（与非网，2026.08）。

但提价是有代价的：智谱年内三次提价累计 83%，调用量不降反增，可在 OpenRouter 的调用排名却从第 3 滑到第 17（虎嗅，2026.05）。**Token 层有提价能力，没有提价特权**——你涨，开发者用脚投票。真正硬气的是短缺的那一层：SemiAnalysis 数据显示，H100 一年期合约租金半年涨了约 40%，到 2.35 美元/卡时；国内 H100 月租站稳 5.5 万–6 万元，新签单交付排到 2027 年。**算力链上谁稀缺谁定价，这条铁律不因计费单位改变。**

券商也闻到了拐点：高盛判断，自 2026 年 4 月以来的激进价格竞争已进入尾声；摩根大通则在 DeepSeek 调价后指出，其行业成本基准的地位并未动摇，反而给其他厂商留出了喘息空间（财新研报精华，2026.08）。价格战的下半场，拼的不是谁更便宜，是谁的成本结构撑得住。

### 终局：上周，DeepSeek 把「分时电价」搬进了 API

干了几年电力交易，我一直说算力定价的终局写在电力市场里：中长期合约锁基本盘，现货市场出清边际，零售套餐卖便利。没想到实锤来得这么快——**8 月 17 日，DeepSeek 正式上线峰谷定价**：高峰时段（9–12 点、14–18 点）价格翻倍，空闲时段半价，V4-Pro 输出高峰 27 元/百万 Token、空闲 13.5 元；一周后又把周末全天统一成低谷价（财新、IT之家，2026.08）。官方说得很直白：用价格杠杆引导错峰，平抑算力负载。媒体管这叫「电力式峰谷定价」。

做电力交易的看到这一幕会心一笑：分时电价、削峰填谷、缓存命中相当于「需求响应补贴」——连工具箱都是同一套。再叠一层「收租+抽成」的双轨：底层资产靠批发长约收租保底，上层价值靠 Token 和分成吃弹性——Kimi K3 提价时已经带上「最高 30% 收入分成」条款（36氪，2026.08），从卖 Token 又往「卖结果」挪了一步。

**所以终局不是谁取代谁，是三句话：定价机制电力化，资产端收租保底，运营端抽成吃弹性。** 先有收租的底子，才有抽成的想象。

### 泼三盆冷水

第一盆，Token 价格远没稳定。一年降价超九成之后又集体回升，DeepSeek 缓存命中价最高涨 1100%——按现价搭成本模型的应用公司，随时要重算账。第二盆，模型效率在涨，单位 Token 的算力消耗在降，同样的「Token 工厂」产能会天然膨胀，长期价格中枢还压着一块石头。第三盆，抽成的前提是生态——没有调度平台和应用入口，你就是个收租的房东，分不到 Token 的羹。商场没客流，再好的抽成条款也是空文。

问题留给大家：**你看到的智算中心，现在收的是表里第几种费？它离「收租 + 抽成」的双轨还有几步？** 欢迎在评论区报一下你了解的项目，咱们一起把这些模式对号入座。一个人捋容易钻牛角尖，一群人捋才能捋透。
