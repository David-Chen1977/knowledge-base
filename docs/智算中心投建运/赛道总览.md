# 智算中心投建运 · 赛道总览

**定义：** 智算中心投建运（Invest-Build-Operate）指智算中心作为重资产项目从投资决策、工程建设到运营管理的全生命周期。核心问题：**从"要不要建"到"建在哪、怎么建、建完怎么赚钱"。**

**成熟度：** 高速成长期（2026 算电协同写入政府工作报告 + 在建产能集中释放）
**PE/VC 重心：** 选址决策、融资结构（REITs/Pre-REITs）、建设交付、算力运营、电力成本管理
**关联专题：** [算电协同](../算电协同/赛道总览.md)（算力×电力协同关系）| 本专题聚焦资产本身的投建运

---

## 一、为什么现在重要？

```
AI 算力爆发 → 智算中心成为新一代基础设施
            ↓
    投：千亿资本开支涌入，但项目回报分化极大
    建：设备交期（变压器160周）卡住扩张节奏
    运：从"包租公"到"算力+能源"运营商转型
            ↓
    核心矛盾：重资产投入 vs 现金流回报周期错配
```

**关键数据：**
- 单座千P智算中心总投资约 20-50 亿元（土建+机电+算力设备）
- 2025-2030 中国数据中心用电量 CAGR 15-20%（AI 训练+推理驱动）
- 2026 年数据中心用电量预计 ~2500-3000 亿 kWh，占全社会用电 ~3%
- 电力成本占智算中心运营成本 30-60%
- 大型变压器交付周期 2026 年已达 160 周以上（GE Vernova）
- 润泽科技 2025 归母净利 50.5 亿（+182%），验证"算力+能源一体化"模式盈利性

## 二、投建运三阶段全景

```
┌─────────────────────────────────────────────────────────────┐
│  投（投资决策）        建（工程建设）        运（运营管理）     │
│  ─────────────        ─────────────        ─────────────     │
│  选址经济学            供配电架构            运营KPI拆解        │
│  融资结构              建设周期与供应链       算力定价模式        │
│  自建vs租赁vs改造      交付与验收            电力成本管理        │
└─────────────────────────────────────────────────────────────┘
         ↓                  ↓                  ↓
    IRR 8%~18%       工期18→30个月         毛利率 20%~60%
```

### 投（投资决策）

| 环节 | 核心变量 | 典型数据 |
|------|---------|---------|
| 选址 | 电价、土地、网络、气候、政策 | 乌兰察布 vs 长三角电价差显著；绿电直连 84 项目、32.59GW 已审批 |
| 融资 | 资本结构、退出路径 | REITs（世纪互联）、Pre-REITs、产业基金、并购 |
| 模式 | 自建/租赁/改造 | 大厂自建、IDC 厂租建、存量厂房改造三足鼎立 |

### 建（工程建设）

| 环节 | 核心变量 | 典型数据 |
|------|---------|---------|
| 供配电 | 冗余等级（2N/4N）、电压等级 | 800V HVDC 全链路直流；柴发+UPS+电池 |
| 散热 | PUE 硬约束 | 新建 DC PUE≤1.15；液冷比风冷节能 30-50% |
| 交付 | 设备交期、建设周期 | 变压器 160 周；总工期从 18 个月拉到 30 个月 |

### 运（运营管理）

| 环节 | 核心变量 | 典型数据 |
|------|---------|---------|
| 效率 | 上架率、PUE、算力利用率 | PUE 降 0.1 + 上架率升 10% → 利润可能翻倍 |
| 定价 | 包机柜/按卡时/按 Token | 三种模式的毛利结构和风险差异显著 |
| 能源 | 电力成本对冲 | 绿电 PPA、储能、需求响应、现货套利四工具箱 |
