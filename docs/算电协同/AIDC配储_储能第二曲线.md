# AIDC配储：储能第二曲线

> 2026年7月12日发布 · 全平台同步 · 含公众号深度文/知乎/头条/雪球/PPT

## 核心观点

- AIDC配储是储能行业的"第二增长曲线"，2026年进入规模化放量阶段
- Oracle为OpenAI密歇根项目1.4GW数据中心配1.383GW储能（1:1配比）——范式转折信号
- 储能角色从UPS备电→需量管理→绿电缓冲，三重叠加

## 全球图谱

| 市场 | 驱动力 | 代表方案 | 配储比例 |
|------|--------|---------|---------|
| 北美 | 弱电网 + 接电周期36-48月 | Tesla Megapack 40%+份额 | 70-100% |
| 欧洲 | 电网瓶颈 + 2030年100%绿电合规 | Sungrow 800V DC | 4-8h储能 |
| 中国 | 绿电直连 + 源网荷储一体化 | 华为战略 + 远景腾讯内蒙实践 | 逐步提升 |

## 产业链受益排序

1. **电芯**：宁德时代(300750)天恒系统 / 比亚迪(002594)刀片 / 海辰储能锂钠混搭
2. **PCS/集成**：阳光电源(300274) PowerTitan / 华为数字能源 iPower AI
3. **海外集成**：Tesla Megapack / Fluence / 南都电源(300068) $4.78亿订单
4. **运营服务**：2028年预计占利润20-30%

## 五个核心判断

1. 2026是规模化放量转折年
2. 海外先于中国爆发（北美2027E:15-20GWh vs 中国5-8GWh）
3. 配储比例将普遍达50-100%
4. 头部电池先行，海外系统集成具估值溢价
5. 三年后看软件和运营
