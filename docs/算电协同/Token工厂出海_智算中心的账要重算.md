**前言**：我干了 20 年地产，管过基金、做过经营性物业的募投管退，最近几年又扎进电力交易和高压直流供电架构。现在开这个号，就是想用"资产 + 电力"的双重视角，把算电协同这件事讲清楚。本文由 AI 协助整理资料和初稿，但每一个判断——比如我说"Token 工厂的生死线不是电价，是稼动率"——都是我自己的体感。也欢迎您在评论区拍砖和切磋。

## 先甩两个打架的数字

8 月 31 日，衡量市场每百万 Token 实际支付均价的 Silicon Data LLM Token Expenditure Index（彭博代码 SDLLMTK）报 **0.97 美元**，是该指数发布以来的最低读数，第一次跌破 1 美元。[1]

这个指数 5 月的高点还在 2.05 美元。三个月跌去一半多，光 8 月一个月就跌了 29%。[2]

谁在把价格往下打？有海外资管人士点名：月之暗面 Kimi K3 这类中国开源模型，定价明显低于美国头部实验室，正在把全市场的边际支付意愿往下拽。[1]

三年前，GPT-4 级别的模型，一百万 Token 的定价还要几十美元。

同一时间轴的另一头：国家数据局披露，中国日均 Token 调用量从 2024 年初的约 1000 亿，涨到 2025 年底的 100 万亿，2026 年 3 月突破 **140 万亿**——两年，涨了一千多倍。[3]

量涨千倍，价跌数十倍。这生意，怎么做？

我干了 20 年地产，看到这组数字的第一反应是：这不就是商业地产里的"客流暴涨、客单价崩盘"吗？商场里人挤人，但每个人只买一瓶水，业主的抽成租金还是上不去。

但真正让我坐直的，是另一件事——就在这条价格曲线一路向下的同时，四川雅安，一座叫"天绛·白泽"的 Token 工厂，在 8 月末点亮投产了。生产智谱、Kimi、DeepSeek 等主流大模型的满血版 Token，投产当月就开始销售放量，9 月规划产能约 3 万亿 Token，年内还要扩两次产，目标月产能 10 万亿。[4]

一边是价格在崩，一边是有人在往里冲。

这个反差，值得捋一捋。

## 从"收租"到"联营扣点"：Token 工厂到底改了什么

先把话说白。

传统智算中心的生意，本质上是收租：把 GPU 按卡时租出去，一租一年，跟我把商铺租给品牌方没区别。

这门生意的好处是简单，坏处是天花板低，而且很脆。行业里公开的数字不太好意思看：未经优化的 GPU 集群，平均利用率只有 **20%–30%**；中小租赁商的毛利率普遍不足 20%。[5]

为什么这么低？因为你的收入跟"硬件被占用的时间"挂钩，而不是跟"这硬件产出了什么"挂钩。租户的业务一进波谷，你的卡就空转。租金照收，但客户续约时一定跟你砍价。

Token 工厂换了个计费单位：不按卡时，按 Token。

这一换，三件事跟着变了。

**第一件，收入从"时间"改成"产出"。** 同一张卡，一天跑 8 小时和跑 20 小时，收入差 2.5 倍。8 月下旬，联想公布过一组数：万全异构智算平台靠 PD 分离、KV Cache 优化、芯模编译优化这一套推理优化，把集群利用率从行业常规的 30% 提到 70% 以上，每百万 Token 的硬件成本压到 1 元以内。[6]

**第二件，客户粘性变了。** 卡时租赁比的是价格，客户随时能搬走。Token 工厂是把 API 嵌进了客户的应用代码和 Agent 工作流里，要搬一次，就得重写一遍调用链路。这跟商业地产里"主力租约"和"散铺短租"的区别是一回事——后者永远在比价，前者到期还会坐下来跟你谈。

**第三件，也是我最想说的：计费单位的改变，把"运营"这件事重新定价了。**

我做地产的时候，商场有两种收租方式。第一种是固定租金，旱涝保收，但涨不上去；第二种是"保底租金 + 营业额抽成"，你要懂品牌、懂动线、懂客流，但商场一旦做起来，业主能吃到增长的红利。

Token 工厂就是第二种。

行业调研纪要里现在跑出来的分润结构，大致是工厂侧拿八成、渠道拿两成——渠道消纳能力强的，分成可以往上谈；也有"保底 + 超额五五分成"的做法：市场租金线以内的部分先保资产方，超出的部分对半分。按这个口径测算，传统裸金属出租净利率约 20%，切换到 Token 分成模式后有望提到 40% 左右。[7]

你看，这就不是什么新词了。这是我熟了二十年的联营扣点。

## 一度电能产多少 Token？现在没人算得清

既然是算电协同，就得回到电。

我原以为这个问题很简单：一度电进去，多少个 Token 出来。查了一圈，发现这个行业连口径都还没统一——而这件事本身，就是个大问题。

东吴证券今年 5 月的测算：百万 Token 耗电约 **0.6 度**，折算下来一度电产出约 **167 万 Token**；按国内大模型每百万 Token 平均超过 8 元的定价，成本约 0.2 元（参考风光上网电价）的一度电，能变成 13 元以上的产出。[8]

另一头，新华社的记者手记援引国内电力机构测算：高强度推理任务下，生成 100 万 Token 平均耗电 **15–20 度**。换算下来一度电只产 5 万–6.7 万 Token，跟东吴的数差了三十倍。[9]

两份信源都不业余，但结论差了一个数量级。为什么？我捋下来，至少四个变量没人统一：

算的是输出 Token，还是输入输出合计？含不含 PUE 和制冷？按空载算还是按满载算？跑的是 7B 的小模型，还是 671B 的大家伙？

这四个变量一动，结果天差地别。

**我的看法是：在"度电 Token 产出"这件事上建立统一口径，是 Token 工厂从概念变成产业的分水岭。** 没有统一计量，就没法定价、没法比选、更没法做资产估值。就像当年商业地产如果没有"建筑面积"和"得房率"的统一口径，租金单价根本没法横向比。

顺带说一个更反直觉的：在全成本口径下，电费并没有大家想的那么吓人。

东吴的拆分是：每百万 Token 的成本里，**设备折旧占 50%–75%，电力只占 12%–14%**。[8]

注意，我说的是**全成本**。如果你只看运营成本（不含折旧），电费占比能到 60%–70%——这也是媒体最爱引用的那个数。[10] 两个数都没错，口径不同而已。

翻译成地产的话：折旧是房贷，电费是物业费。一套房子每个月的现金支出里，物业费确实占大头；但要算总账，压死你的是房贷。

**所以我的第一个判断是：做 Token 工厂，降电价是加分项，不是生死线。真正的生死线是稼动率——你的卡，一年到头有多少时间在生产 Token。**

不过这里有个时间维度的反转，得提醒一句：随着芯片能效提升、服务器价格下行，折旧占比会逐年下降，电力的占比反而会往上走。今天一成多的电，五年后可能是三成。

算电协同不是现在不重要，而是它的重要性在往后逐年加码。

## 三道坎：不是有卡就能叫"工厂"

**第一道坎：稼动率。**

腾讯云解决方案总经理张晋今年 7 月在 MWC 上海"智能数据中心峰会"上给过一个数：国内智算中心 GPU 平均利用率不足 30%。[11]

原中国电信科技委主任韦乐平说得更直白：国内 280 多个智算中心，GPU 利用率很不均衡，"饱的撑死，饿的饿死"，平均不到 30%。[11]

中国信通院的数据是，2025 年国内智算共算量约 38 亿卡时，用算量只有 14 亿卡时，用算占比 36.8%。[11]

三个来源，一个结论：**每投 100 块钱建算力，大概 70 块钱在空转。**

但这不是命运。并行科技对财联社披露，公司 2025 年算力服务营收 10.2 亿元，算力利用率在 90% 到 95% 之间，头部企业订单排期已经到了 2028 年。[11]

同期，另一边高端算力缺得厉害：信通院数据，2026 年一季度国内 AI 算力需求同比涨 417%，有效供给只涨 128%；工信部披露的口径是，高端训练算力有效供给只能满足不到 47% 的市场需求，缺口约 35%。[12]

一边 70% 空转，一边 35% 缺口——这在我的老本行里叫"结构性空置"。不是没需求，是你的铺子不对路。

**第二道坎：适配。**

这条最容易被做资产的人忽略。

雅安那座工厂投产时，官方报道里有一句话我印象很深：一座真正的 Token 工厂要过三重门槛——稳定的算力基础设施、面向主流大模型的适配与推理优化能力、可持续的运营商业化能力。[4] 三条里有两条是"软"的。

硬的卡大家都买得到，软的功夫买不来。模型不预适配，客户拿到卡也跑不起来，迁移的人力和时间成本会直接把客户劝退。联想那个"利用率从 30% 到 70%"的案例，靠的也不是换卡，是调度平台和推理优化。[6]

地产类比：毛坯交付和精装带租约交付。房子是同一套，后者出租率高出一大截，因为客户拎包就能开业。Token 工厂卖的不是裸算力，是"能直接跑起来的产能"。

**第三道坎：价格通缩撞上刚性成本。**

这是最要命的一道。

8 月的数据最刺眼：摩根大通的统计，OpenRouter 平台 Token 使用量环比涨了约 47%，美元支出只涨了约 7%。量在暴涨，钱几乎没动。[2]

成本端呢？高盛的统计是，五家获评级的超大规模云厂商 2026 年资本开支合计约 **7370 亿美元**，约占其收入的 38%。这笔钱是已经承诺出去的、锁死的。还有一个更冷的信号：2026 年发行的 91 只超大厂债券里，8 月底前已有 78 只跌破发行价——信用市场已经在重新定价了。[2]

收入端在通缩，成本端在爬坡。这个剪刀差，商业地产在 2019 到 2023 年走过一遍，那时候的说法叫"租金覆盖不了利息"。

对 Token 工厂来说，它的特殊性在于：**折旧是按时间计的，收入是按产出计的。**

你的卡不管有没有订单，折旧照提；而产出的单价还在往下走。这等于把"空置风险"和"价格风险"同时扛在了自己身上。

这也是为什么我认为，Token 工厂不是所有玩家都能上的牌桌。它把智算中心从"资产持有"推向了"生产制造"——制造业的命门是产能利用率和单位成本，不是地段和估值倍数。

## 一道行业内部还在吵的题：工厂该建在哪？

这个问题我特意留出来，因为我确实没想透，想听听各位的。

**一边是"往西走"。** 逻辑是电价。西部枢纽的绿电价格能打到 0.3 元/度上下，雅安的水电就在这一档。[4] 政策也在推：2026 年政府工作报告首次提出"实施超大规模智算集群、算电协同等新基建工程"；绿电约束也在收紧——发改委等四部门 2024 年就提出"到 2025 年底国家枢纽节点新建数据中心绿电占比超过 80%"，国家数据局今年 3 月再次明确，要确保枢纽节点新建算力设施绿电应用占比达到 80% 以上。[13]

**另一边是"往东靠"。** 逻辑是时延。前面算过账，全成本口径下电费只占一成多，省下的电费有限；但时延一上去，你的 Token 就卖不上价——同样的卡，放在东部核心城市旁边能卖高价，放到几千公里外可能要打折。

两边都有数据，都有人押注。

我目前的倾向是：**这不是一道单选题，而是一道分类题。**

训练、离线批处理、视频渲染这类不挑时延的活儿，可以跟着绿电走，还能当电网的"海绵负荷"用——大风季、丰水期就多开工。而实时对话、Agent 这类要抢毫秒的活儿，必须贴着客户建。

但这是我的推论，不是结论。如果你在一线做调度，欢迎在评论区拍我。

## 往后三年，三个方向

**方向一：计价单位还会往下沉一层。**

从"卡时"到"Token"是第一步，下一步是"业务结果"。行业里已经有人在提分级交付：卖算力是一层，卖 Token 是一层，再往上是卖场景化的能力包。

这件事对做资产的人意义很大。卖卡时的收入不可预测，卖 Token 的收入可测算，卖场景包的收入才可能被资本市场当成"类订阅收入"来给倍数。地产里也这样：散铺租金给 5 个点，带 15 年长约的整栋写字楼，资本化率能低到 4 个点出头。现金流的稳定性，本身就是估值。

**方向二：Token 工厂会成为电力系统最好的"可调节负荷"。**

这是我最兴奋的一点，也是我觉得算电协同真正的增量所在。

推理任务里有一大类是可以等的：离线批处理、模型后训练、视频渲染、数据清洗。这类任务不看地理位置，只看网络。换句话说，Token 工厂的这部分负荷是可以"追着电价跑"的——电价低、绿电足的时候多开工，电价高、电网紧的时候主动降载。

比起重卡超充那种必须在固定地点、固定时间出现的负荷，Token 工厂的负荷弹性好得多。它不需要建在充电桩旁边，也不需要用户配合。

过去我们说"算电协同"，讲的是电力怎么保算力；往后可能要反过来讲——**算力怎么帮电力消纳**。

**方向三：资产会分层，而且分得很快。**

我的判断很直接：未来两年，智算中心的估值会出现剧烈分化。

跑通稼动率、有稳定 Token 现金流、有长约客户的工厂，会被当成"能产生现金流的经营性资产"来定价，甚至具备被并购、被证券化的可能。跑不通的那批，会变成算力版的"烂尾楼"——账面有资产，现金流为零，每年还要付电费和利息。

分水岭在哪？就三个数：稼动率、Token 单价、客户合约期。跟当年判断一个商场值多少钱看的是出租率、租金单价和租期，一模一样。

## 写在最后

回到开头那个数字：0.97 美元。

单看这个数，你会觉得 Token 这门生意没法做了。但把它和另一个数放在一起看——140 万亿的日均调用量——你会发现，崩的不是需求，是定价权。

Token 工厂真正的意义，不是给算力换个计价单位，而是倒逼这个行业从"占资源"转向"做运营"。占资源这几年已经把钱赚完了。接下来赚的，是稼动率、是调度、是软硬一体的那点笨功夫。

我干了 20 年地产，见过太多"位置好就躺赢"的故事，也见过太多空置的商场。**算力资产这一轮，位置只是入场券，稼动率才是生死线。**

一个人捋容易钻牛角尖。上面那道"工厂建在哪"的题，我是真没想透，评论区交给大家。
